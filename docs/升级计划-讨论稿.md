### P1 — 影响体验和维护，建议排第二梯队

**5. 三个巨型文件**

`EnglishLearning.tsx` 一个文件 3156 行，管 8 个页签。改一个页签要在三千行里找地方，容易误伤旁边的。这个不致命，但它是后面所有改动变慢的根源。

**6. 生词数据三处存放，互不相通**

我查了类型定义，现在跟"生词"有关的存了三份：

- `StudyWord`（单词本）—— 只有 `word/phonetic/meaning/sentence`，**没有"掌握没有"这个状态**，也就没法做复习
- `StudySentence.words`（语句本里句中标记的生词）—— 第三份
- 剧有词的词库 —— 自己有一套 `new/later/known/fuzzy` 状态，但**只服务它自己的测验，不回写单词本，也不参与同步**

结果：在 TED 里标的词、在剧有词里标的词、在句子里标的词，各在各的地方。用户感知是"我标过这个词，怎么又要标一遍"。

**7. 学的东西不同步**

同步只同步 `notes` + `customWords` + `customSentences`。不同步的有：

- 剧有词的词库和测验状态
- TED 精听进度、标记了哪些句子
- 「问 AI」历史（200 条）
- 双语对照历史（30 条）
- TED 字幕的翻译缓存（`ted-trans-*`，按篇存）

手机上学一半的 TED，回到电脑要从头点。这个我觉得是比较伤的。

**8. TED 精听断网就废**

mp4 在 `py.tedcdn.com`，字幕 JSON 虽然构建进了本地，但视频必须联网。地铁上、飞机上用不了。

**9. 免费 AI 通道时好时坏**

Pollinations 匿名通道连发容易 402，主进程有退避重试，但用户感知就是"刚才还能用，现在又不行"。没有"正在重试"的提示，用户以为坏了。

**10. 没有数据导出/导入**

学习数据全在 localStorage。清浏览器数据、换手机、换电脑，**全丢**。同步只同步三类，其他都没兜底。这是真风险，不是理论风险。

## 四、可以往哪发展（三档，每档我给判断）

### A 档 · 英语主轴做深（我最推荐先动这里）

**A1. 生词复习调度**
现在生词本是"存起来"，不是"记住"。加一层：标"认识/模糊/不认识"，按熟悉度排下次什么时候出现（间隔重复）。这是单词类软件最核心的缺口，做下来这个软件的性质就变了——从"记录工具"变成"学习工具"。
*难点*：要把状态加进 `StudyWord`，就要动同步结构，得同时想好老数据怎么迁移。

**A2. 学习数据看得见**
连续学习天数、每天完成没有、生词涨了多少。成本低，但反馈强——现在学完没有任何"我在进步"的感觉。
*这块现在有一半基础*：`english-learned-${日期}` 这个 key 已经在记了，只是没展示。

**A3. 精听记录打通单词本**
TED/追剧里标的词、句子，一键进单词本（入口已经有了），进的时候把状态、来源（哪篇 TED 第几句）一起带过去。这样复习的时候有上下文，比干背一个词好记。

### B 档 · 底座（不性感，但决定能走多远）

**B1. 数据导出/导入**
一键导出全部学习数据成 JSON，也能导回来。换设备、清缓存有兜底。**这个我认为是 P1 里最该先做的**，因为它防的是"全部归零"。

**B2. 把 `EnglishLearning.tsx` 拆开**
按 8 个页签切成 8 个文件，父组件只留共享状态。拆完再加功能才敢动手。

**B3. 最小测试**
不用大动干戈，先把 `sync-core.ts` 的合并逻辑、`parseShowsText` 的 JSON 容错这类纯函数罩住。这两个地方最容易在改动中悄悄坏掉，而且坏了不易发现。

### C 档 · 新方向（想清楚再动）

**C1. 追剧精听做成"按集收集词汇、反复练"（你提的方向，重做）**
你原来的设想：看到《某剧》第几集，告诉 AI，它就**把那集的生词收集起来，能反复练习**——而不是像现在这样要自己找视频、下载、再上传才能学。
这条跟 A1 复习调度是连着的：收集来的词 → 进间隔重复练习。
**已定（你选的）**：只说"《剧名》第几集"，AI 凭记忆生成词表 → 进复习调度反复练。最快、零准备。
**我加的保险**：AI 出的词表标"AI 生成"，你能改 / 删 / 补；它不是那集逐句字幕词，是"这一剧 / 这一级大概率会遇到的词"，跟你看的那集不一定逐句对上——但作为练习材料够用，不准也不碍事（随时能改）。冷门剧 AI 容易编错，到时提醒你以"改过的"为准。

**C2. 更多免费视频**
35 篇 TED 会听腻。抓取脚本是现成的（`scripts/fetch-ted.mjs`），加 slug 就能扩。但版权内能自动给的源很少——TED 基本是唯一一个。这条投入小、天花板也低。

**C3. 笔记和英语打通**
看视频记的笔记里标出生词，一键进单词本；反过来单词本里的词能回跳到原句子。两块现在是分开的两个世界。
