# 手机版全功能复刻与坚果云全量同步设计文档

日期：2026-08-23

## 1. 目标

让手机版笔记本成为电脑版的移动端入口，做到：

1. 手机不需要和电脑在同一 Wi-Fi，通过固定公网网址即可打开。
2. iPhone 和 Android 都能使用，并可以添加到手机主屏幕。
3. 手机版复刻电脑版除视频、网页模块外的全部功能。
4. 电脑和手机通过坚果云同步全部学习数据，任一端打开页面就能看到另一端的内容。

## 2. 范围

本轮交付包含：

- 统一代码库：电脑 Electron 版与手机 PWA 共用 React 应用，不再维护两套业务代码。
- 手机触屏布局与 PWA：笔记、英语、计划、资料、我的五个主入口。
- 全量同步：课程、笔记、生词/语句、学习计划、资料库、标记全部双向同步。
- 资料文件双向可用：桌面本地文件上传到坚果云，手机可下载打开；手机添加的文件上传后电脑也能看到。
- 桌面二维码配网：手机扫码自动填入坚果云配置。
- GitHub Pages 公网部署，并保留手动配置入口。
- 交付前完成构建、浏览器模拟、同步流程、PWA 安装验证。

本轮明确不做：

- 手机版视频模块和网页内嵌模块。
- 窗口置顶、窄条模式等 Electron 系统能力。
- 新增其他网盘或第三方同步服务，继续使用坚果云 WebDAV。

## 3. 技术栈

- Electron + Vite + React + TypeScript，桌面端保持现状。
- TipTap 富文本编辑器，两端共用同一套笔记数据格式。
- Lucide 图标与现有主题、背景设计体系。
- Service Worker + manifest + PWA 图标，使手机版可安装到主屏幕。
- `qrcode` 生成桌面配对二维码，`jsqr` 在手机端扫码。
- 坚果云 WebDAV 作为唯一云端同步服务。

## 4. 架构

### 4.1 代码结构

- `electron/`：桌面主进程与预加载脚本，继续负责本地文件、窗口、系统能力。
- `src/`：React 渲染进程，电脑与手机共用业务组件、数据模型和同步逻辑。
- `src/lib/sync.ts`：新增共享同步引擎，封装坚果云拉取、合并、上传、文件资源同步。
- `src/browserAdapter.ts`：扩展浏览器端数据适配，负责手机版 localStorage 读写与 WebDAV 请求。
- `public/` 或等效 PWA 目录：manifest、service worker、应用图标，随构建产物部署。
- `mobile/`：旧独立手机页面退役，不再作为正式手机版发布源。

### 4.2 运行环境区分

- Electron 环境存在 `window.studyNotes`，显示完整桌面功能，包括视频、网页模块和系统窗口能力。
- 浏览器环境不存在 `window.studyNotes`，自动进入手机 PWA 模式，隐藏视频、网页、置顶、窄条入口。
- 两种环境共用课程、笔记、英语、计划、资料、标记、主题、背景等组件。

### 4.3 数据模型

云端统一数据文件：

```text
gaga-study-data.json        课程、笔记、生词/语句、计划、资料库、标记
gaga-study-assets/          图片、录音、资料文件等二进制文件
```

数据文件按实体维护 `updatedAt`；二进制文件按内容哈希命名，重复文件不重复上传。

## 5. 手机界面与功能布局

手机打开后直接进入“笔记”主界面，不展示落地页。顶部保留 GaGa 标志与同步状态，底部固定五个标签：笔记、英语、计划、资料、我的。

- 笔记页：课程分类树、标题/标签搜索、新建笔记；点开进入全屏编辑器。
- 编辑器：标题、加粗/斜体/下划线、多级标题、列表、引用、代码块、高亮/文字颜色、字号、插入图片、整页标记画板、录音，修改自动保存。
- 英语页：每日单词/语句、单词本/语句本、单词与整句默写、朗读/慢速朗读、每日目标与学习模式、朗读自己的英语文本。
- 计划页：添加、完成勾选、删除、到点提醒；手机端使用 PWA 通知。
- 资料页：课程链接、资料笔记、文件三种资源；链接用手机浏览器打开，文件从坚果云下载后用手机自带程序打开或保存。
- 我的页：扫码配网、手填坚果云配置、数据统计、主题/背景设置、安装到主屏幕入口、清空本机数据。

## 6. 同步与冲突处理

### 6.1 同步触发

- 电脑启动时自动拉取；新增、修改、删除后自动上传。
- 手机打开页面时自动拉取；新增、修改、删除后自动上传；切回前台时再次拉取。
- 两端都保留手动“立即同步”入口。

### 6.2 合并规则

- 按实体合并，不整份覆盖：每篇笔记、每条生词/语句、每条计划、每个资源、每条标记都有独立 `updatedAt`。
- 云端与本地比较后，修改时间较新的实体保留；同一秒修改时用设备标识做确定性排序。
- 删除使用墓碑标记同步到另一端，避免删除被旧数据复活。

### 6.3 文件资源

- 电脑端本地资料文件上传到 `gaga-study-assets/`，手机端点击时下载到临时文件，再交给手机系统打开。
- 手机端通过文件选择器添加的图片/文件上传到云端，电脑端拉取后放入本地资料目录。
- 文件按内容哈希增量同步，已存在的文件不重复上传。

### 6.4 错误处理

- 网络或 WebDAV 失败时只提示同步状态，不修改本地数据。
- 下次打开页面、切回前台或手动同步时自动重试。
- 同步配置只保存在桌面 `userData/sync-config.json` 与手机 `localStorage`，不写入云端数据文件。

## 7. 二维码配网与安全

- 电脑同步面板新增“生成配对二维码”，内容为坚果云配置 JSON。
- 手机“我的”页提供“扫一扫”，使用摄像头识别后自动填入并保存。
- 手填坚果云地址、账号、应用密码入口保留。
- 二维码只在电脑屏幕显示，不写入云端、GitHub 仓库或公开网页。
- 手机访问坚果云使用 HTTPS，账号密码通过 Basic Auth 传递；CORS 代理前缀可配置，默认沿用 `https://corsproxy.io/?url=`。

## 8. PWA 主屏幕安装

- manifest 配置 `display: standalone`、名称、图标、主题色，支持 iOS 与 Android。
- 提供 192px 与 512px 图标及 `apple-touch-icon`。
- Service Worker 缓存应用外壳，打开过一次后弱网/离线也能启动。
- 手机端提供“安装到主屏幕”入口：Android 触发浏览器安装流程，iOS 引导系统“添加到主屏幕”。

## 9. 部署、测试与交付

### 9.1 部署

- `npm run build` 构建 React 手机版，生成 PWA 文件。
- 部署脚本把构建产物推送到 GitHub Pages，正式网址为 `https://<用户名>.github.io/gaga-notes-mobile/`。

### 9.2 交付前测试

- TypeScript 与 Vite 构建通过。
- 本地服务器下分别模拟 iPhone 与 Android 视口，检查布局、底部导航、编辑器、触屏操作。
- PWA 可安装、Service Worker 缓存、manifest 在 iOS/Android 规则下正确。
- 使用模拟 WebDAV 验证“电脑写 → 手机拉取 → 手机写 → 电脑拉取”全流程，包括文件上传/下载。
- 验证二维码生成、手机扫码填入配置流程。
- 全部通过后部署正式网址并交付。

## 10. 验收标准

- 手机在任意网络下打开固定网址即可使用。
- iPhone 与 Android 均可添加到主屏幕并独立启动。
- 手机端可用功能与电脑端一致，仅视频、网页、系统窗口能力除外。
- 电脑端写入的笔记、英语、计划、资料、标记在手机打开页面后可见。
- 手机端新增或修改的内容在电脑端拉取后可见。
- 资料文件在两端都可打开或保存。
