# 学习笔记桌面软件设计文档

日期：2026-08-20

## 1. 目标

做一款本地桌面学习笔记软件：上课时可以一边看视频，一边在旁边记笔记。支持内置播放本地视频、用内置浏览器打开网课链接，也可以切到窄条模式贴在其他视频窗口旁边使用。

## 2. 范围

第一版包含：

- 桌面双栏界面：左侧视频，右侧笔记，中间可拖拽调比例
- 纯笔记窄条模式和窗口置顶
- 本地视频播放与网页链接内嵌打开
- 富文本笔记、多课程管理、标签、大纲、全文搜索、笔记互链
- 视频时间戳标记、文字高亮、截图标注
- 粘贴/拖入截图、视频画面一键截图、录音并插入笔记
- 自动保存、导出 Markdown/HTML

## 3. 技术栈

- Electron + Vite + React + TypeScript
- TipTap 富文本编辑器
- Lucide 图标
- Fuse.js 全文搜索
- 本地文件存储，数据保存在应用用户数据目录

## 4. 架构

### 4.1 进程划分

- 主进程：创建窗口、窗口置顶、原生菜单、文件对话框、BrowserView 网页播放、本地文件读写
- 预加载脚本：通过 contextBridge 暴露受限 API，开启 `contextIsolation`，关闭 `nodeIntegration`
- 渲染进程：React 界面、TipTap 编辑器、视频播放、截图标注画布、录音

### 4.2 界面布局

- 顶部工具栏：视频/笔记切换、插入时间戳、截图、录音、置顶、窄条模式、导出
- 可折叠侧边栏：课程树、笔记列表、标签、大纲、搜索
- 主区域：左侧视频、右侧笔记，拖拽分隔条
- 状态栏：自动保存状态、录音状态、视频进度

### 4.3 数据模型

```text
用户数据目录/StudyNotes/
  library.json          课程、笔记、标签、时间索引
  notes/<noteId>.json   单篇笔记（TipTap JSON + 元数据）
  assets/               截图、录音、标注图片
```

笔记元数据包含：标题、所属课程、标签、创建/修改时间、大纲（由标题生成）、笔记内链。

## 5. 功能模块

### 5.1 视频

- 本地文件：拖入或选择文件，HTML5 播放器，支持倍速和截图当前帧
- 网页链接：粘贴 URL，通过 BrowserView 打开；遇到无法内嵌的站点，回退到外部浏览器
- 时间联动：点击笔记中的时间戳，视频跳转到对应位置

### 5.2 笔记编辑器

- TipTap 支持标题、加粗、斜体、列表、代码块、引用
- 自定义节点：视频时间戳、图片（含标注图）、录音块

### 5.3 三类标记

- 视频时间戳：插入当前播放时间，点击后跳转
- 文字高亮：选中文字后选择高亮颜色
- 截图标注：对插入的截图用画布标注箭头、矩形、自由笔迹、文字，确认后替换为标注图

### 5.4 截图与录音

- 截图：粘贴、拖入、一键截取当前视频画面
- 录音：MediaRecorder 录制，结束自动插入笔记内联播放

### 5.5 知识库能力

- 多课程、多笔记
- 全文搜索、标签筛选、大纲跳转、笔记内链
- 自动保存（防抖 1 秒，临时文件原子替换）
- 导出 Markdown/HTML

## 6. 数据流

1. 启动时主进程读取 `library.json`，返回课程与笔记索引
2. 打开笔记时渲染进程通过 IPC 获取笔记 JSON
3. 编辑后防抖保存，写临时文件后替换，并更新索引
4. 搜索索引在启动和每次保存后重建

## 7. 错误处理

- 保存失败：状态栏提示，提供重试
- 资源文件损坏：跳过该资源并在界面提示，不阻塞笔记打开
- 崩溃恢复：检测未完成的临时文件并清理
- 网页站点无法内嵌：提示切换到外部浏览器

## 8. 测试与验收

- 数据层单测：保存、索引、搜索、导出
- 手工验收清单：
  - 本地视频可播放、可截图
  - 网页链接可打开，失败可回退
  - 三类标记可用
  - 录音插入可播放
  - 窄条模式与置顶正常
  - 重启应用后数据不丢

## 9. 开发节奏

1. 搭骨架：窗口、布局、窄条模式、置顶
2. 视频：本地播放、网页打开、时间戳
3. 知识库：笔记树、富文本、自动保存
4. 标记三件套 + 录音 + 搜索 + 导出
5. 界面打磨与打包
